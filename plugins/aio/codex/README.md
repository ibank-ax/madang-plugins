# AIO.MADANG — aio@madang

플러그인 버전 `0.1.0` · 제품 원천 커밋 `b3923ac55cb8a0573d626abb4d86c6e6bff7ddae`

공개 마켓플레이스의 설치 패키지는 원격 HTTP MCP와 OAuth를 사용합니다. 기본 서버 이름은 `aio`, 주소는 `https://aio.madang.ai/mcp`입니다. 토큰 복사나 로컬 bridge 실행은 설치 조건이 아닙니다.

## Codex 설치

마켓플레이스를 등록하고 플러그인을 설치한 뒤 새 대화의 MCP 연결 목록에서 OAuth 로그인을 시작해 주세요.

```text
codex plugin marketplace add https://github.com/ibank-ax/madang-plugins
codex plugin add aio@madang
```

마켓플레이스 등록 출처는 `https://github.com/ibank-ax/madang-plugins`입니다. Claude Code에서는 canonical HTTPS Git URL을 사용합니다. 기존 출처와 충돌하면 현재 오류와 선언을 확인하고 설정을 백업한 뒤 해당 출처만 교정합니다. 플러그인 삭제·전체 설정 초기화를 기본 해결책으로 삼지 않습니다.

## 로그인과 권한

첫 사용 때 OAuth 연결을 시작하고, 이메일로 소속 조직을 찾은 다음 해당 조직 주소에서 로그인합니다. 이메일 입력, 허브 SSO 로그인, 서비스 이용약관 동의는 MCP 연결 승인을 대신하지 않습니다. 요청한 앱과 조직·사이트·범위를 확인한 뒤 연결을 명시적으로 허용하거나 거부합니다.

에이전트에 `invalid_client` 또는 클라이언트 등록 실패가 표시되면 해당 에이전트에서 연결을 다시 시작합니다. 에이전트가 등록 정보를 새로 준비한 뒤 사용자가 로그인과 명시 동의를 다시 진행해야 합니다. 화면 새로 고침·토큰 붙여넣기·사용자 클릭 없는 조용한 재인가를 복구 절차로 안내하지 않습니다.

공개 클라이언트는 DCR(`token_endpoint_auth_method=none`)로 등록하며 수명은 무기한입니다. 90일 자동 만료는 없습니다. 같은 등록을 재사용하고 `invalid_client`가 발생하면 소비자가 캐시를 무효화해 재등록한 뒤 사용자가 명시적으로 재연결합니다.

첫 제공 범위는 `answers:read`의 `answers.get_answer` 한 개입니다. 민감·쓰기 scope는 없습니다. 기존 답변만 읽으며 현재 조직의 활성 회원·사이트 membership·viewer 권한을 매 호출 시 서버가 다시 검사합니다. 수집·생성·차감·설정 변경·배포 도구는 포함하지 않습니다. 플러그인과 직접 MCP는 같은 서버·OAuth·scope·권한 검사를 사용합니다.

본인 조직 주소의 `/aiso/me/mcp`에서 본인 연결을 확인하고 하나씩 해제합니다. 본인 계정의 모든 조직을 합쳐 활성 연결 상한은 5개입니다. 새 연결의 토큰 교환이 성공해 상한을 넘을 때만 가장 먼저 연결한 항목을 해제합니다. 실패하거나 만료된 요청은 기존 연결을 유지합니다.

상한을 넘을 새 연결에는 동의 화면에서 해제할 실제 앱 이름·최초 연결 시각을 예고합니다. 같은 client 재승인이나 5개 미만인 요청의 해제 예고는 없습니다. 본인 연결 관리에서 수동 해제와 해제 사유·시각을 확인할 수 있습니다.

## 그 밖의 에이전트

원격 Streamable HTTP 주소 `https://aio.madang.ai/mcp`과 클라이언트의 OAuth 로그인을 사용합니다. 아래는 일반 설정 예시이며, 파일 위치와 설정 키는 클라이언트 안내를 따릅니다.

```json
{"mcpServers":{"aio":{"url":"https://aio.madang.ai/mcp"}}}
```

## 확인할 증거

패키지 존재·설치 성공은 OAuth 승인이나 실제 읽기 성공을 뜻하지 않습니다. 공개 마켓플레이스 등록, 엔진·버전별 설치, 실행 세션 HTTP 설정·인가 시작, 조직 로그인·명시 승인, 실제 `answers.get_answer` 호출을 각각 확인합니다. 직접 MCP도 discovery·OAuth·tools/list·실제 읽기를 각각 확인합니다. 인가 주소·pending·nonce·code·token 원문은 보고서나 로그에 남기지 않습니다.

이 README 템플릿의 최초 작성 시점에는 공개 마켓플레이스 게시·생성/export·설치·OAuth·실제 호출을 실행하지 않았습니다. 이후 릴리스의 실제 게시·수용 여부는 해당 릴리스 기록으로 별도 확인합니다.

Cursor의 표시 제목은 메타데이터만으로 보장하지 않습니다. 실제 카드 표시·세 엔진 설치·OAuth·실제 읽기·회수는 각 릴리스의 수용 기록으로 별도 판정합니다.
