name: aca-setup
description: ACA 조직 주소의 native HTTP MCP 연결과 본인 OAuth 연결 상태를 확인한다.
---

ACA.MADANG 조직 주소의 `/mcp`를 사용한다. 공용 조직 찾기·수동 key·Campaign 원자격 전달·자동 동의는 제공하지 않는다. 처음에는 기존 ACA 자체 로그인을 한 뒤 사용자가 요청 앱·돌아갈 주소·읽기 권한을 보고 연결을 명시 허용한다. 이미 로그인했더라도 허용을 대신하지 않는다.

서버 준비/계정 proof가 없으면 미준비를 그대로 알린다. 플러그인 설치 성공·버전 갱신·로그인 성공과 MCP 승인·도구 성공을 구별한다. 권한 오류를 우회하거나 새 Logon·자격 입력을 요구하지 않는다. 연결 상태와 해제는 같은 조직 주소의 `/mcp/connections`에서 확인한다. 연결을 해제한 뒤 같은 token 호출이 거부되어야 완료다.
