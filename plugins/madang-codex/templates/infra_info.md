# 프로젝트 인프라 환경정보

이 양식은 비밀 없는 환경정보 정리본이다. 프로젝트의 `docs/env/infra_info.md`에 새로 만들거나, 사용자가 이미 관리하는 정리 문서의 경로를 사용한다. 기존 파일을 덮어쓰지 않는다. 확인되지 않은 항목은 `미확인`으로 두며 이 파일 작성만으로 데브마당 등록 완료가 되지 않는다.

비밀번호·개인키·토큰·환경변수 값·실제 접속 주소·계정은 기록하지 않는다. 접속정보와 비밀값은 지원되는 보호 입력에서 저장하고 이 문서에는 요청/연결 ID·버전·상태만 적는다. 비밀 원문이 있는 별도 파일을 복사하거나 그 본문을 대화에 붙이지 않는다.

## 출처

- 프로젝트 코드 / 데브마당 projectId: 미확인
- 별도로 관리하는 환경정보 정리 문서 경로 또는 참조: 미지정
- 출처 판본 / 확인 일시: 미확인
- 이번에 확인한 범위 / 아직 필요한 자료: 미확인

## 환경과 목적

- 실제 제공 환경 수: 미확인
- 기존 환경 키 / 논리 환경 / operatingMode: 미확인
- 개발(development) / 검수(verification) / 운영(operations) 목적 매핑: 미확인
- 환경 정책 버전 / 저장 확인: 미확인

단일 운영 환경을 함께 쓰는 경우 `prod` 하나에 세 목적을 매핑한다. 기존 `test` 등의 별칭·대상 ID는 임의로 변경하지 않는다. 서버 대수나 preview URL 개수는 환경 수가 아니다.

`hasMaterial=false` 또는 키 이름만 등록한 문서는 값 미저장이다. `hasMaterial=true`도 문서 단위 저장 메타데이터이며 개별 키 값의 정확성이나 실제 환경 적용을 증명하지 않는다. 조회 결과에 없는 필드는 미확인으로 남긴다.
