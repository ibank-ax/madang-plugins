# UX.MADANG 연결

MCP 서버 `ux`의 공용 주소는 `https://ux.madang.ai/mcp`다. native HTTP/OAuth를 사용하며 수동 키·client ID·로컬 bridge를 만들지 않는다. 설치나 기존 웹/SSO 세션은 MCP 인증·동의가 아니다.

1. 클라이언트 MCP 연결의 Authenticate/Connect로 시작한다. 회사 찾기·메일의 정상 조직 경로에서 로그인하고 실제 표시된 클라이언트와 `ux:read`를 확인한 뒤 사용자가 연결을 허용하거나 취소하게 한다. 자동 승인·동의 API 대리 호출을 하지 않는다.
2. 이미 알려진 접근 가능한 프로젝트 UUID로 `get_project`를 호출한다. UUID가 없으면 사용자에게 프로젝트 참조를 요청한다. 임의 ID·다른 tenant/Host·역할 header를 만들지 않는다. 읽기 확인을 위해 새 분석이나 쓰기를 실행하지 않는다.
3. 401은 만료/회수를 확인하고 정상 OAuth 재연결을 안내한다. 403/404는 현재 권한·존재 여부를 확인한다. 503은 서버/계정 연결 준비 또는 판정 미완료로 남기며 성공·0개·권한 확대·자동 재동의로 대체하지 않는다. 429는 서버가 제시한 간격을 따른다.
4. 다른 조직으로 전환할 때는 본인 연결 관리에서 기존 연결을 해제하고 대상 조직에서 다시 로그인·명시 동의한다. 활성 연결은 계정 전체 조직 합산5개이며 6번째의 실제 token 교환 성공 시 oldest가 해제된다. 새 연결의 영향은 서버 preview를 따른다.

패키지 제거와 서버 grant 회수를 구분한다. 본인 해제 결과와 원래 토큰의 거절을 실제로 확인하기 전 회수 완료라고 하지 않는다. 토큰 교환 결과가 불명일 때 새 code/승인 POST를 자동 재전송하지 않는다. 오류를 전달할 때 session·code·token·cookie·인가 URL 원문은 싣지 않는다.
