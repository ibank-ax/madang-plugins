# ASSET.MADANG 설치 패키지

Claude Code, Codex, Cursor용 ASSET 패키지입니다. 제품 원천에서 원격으로 생성·검증한 세 IDE 패키지 15파일을 수정 없이 제공합니다.

## 패키지와 서비스 연결

공개 패키지를 내려받거나 설치하는 것은 ASSET 서비스 접근 권한을 부여하지 않습니다. 실제 운영 MCP·SSO·OAuth 로그인 및 검색 도구 수용은 아직 이 패키지 검증으로 확인하지 않았습니다. 조직 계정과 사용자의 명시적 연결 허용이 필요하며, 설치·로그인만으로 연결 성공으로 처리하지 않습니다. 키·토큰을 패키지나 설정 파일에 넣지 않습니다.

공통 마켓플레이스의 ASSET 항목은 별도 통합 작업입니다. 그 항목이 반영되기 전에는 `asset@madang`을 설치 가능한 등록 항목이라고 안내하지 않습니다. 직접 설치를 지원하는 IDE에서는 아래의 해당 엔진 폴더를 선택하고 그 폴더의 README를 따릅니다.

- Claude Code: `claude/`
- Codex: `codex/`
- Cursor: `cursor/`

패키지의 생성 당시 안내·출처 메타데이터는 그대로 보존했습니다. 거기에 적힌 로컬 패키지 상태는 생성 회차의 기록이며, 공개 카탈로그 통합·실제 IDE 설치·운영 서비스 수용을 대신하지 않습니다. 파일/매니페스트 검증은 실제 연결·검색 검증과 구분합니다.

## 출처

제품 버전은 `1.0.0`, 생성 원천은 `b0877bbce3f8fdfc2e765c1243a076cb2de4be4f`입니다. 해당 생성 원천과 통합 source `de7262736c21b3ea59f05485f37c91f07226f434`, 실제 병합 `996cf9f2fa37023d06306fc1e918218e260cbe90`의 tree는 같습니다. 원격 생성 수신증과 15파일의 해시는 `products/asset.json`에 기록했습니다.

문구·스킬·매니페스트 변경은 비공개 제품 원천과 exporter에서 처리하며, 이 생성물을 직접 수정하지 않습니다.
