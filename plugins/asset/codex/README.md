공개 MCP 주소: `https://asset.madang.ai/mcp`. 조직 주소·키·토큰·환경 변수 입력은 필요하지 않습니다.

이 폴더는 공개 게시 전 로컬 설치용 패키지입니다. IDE가 지원하는 로컬 플러그인 설치로 이 엔진 폴더를 선택한 뒤 MCP 연결 화면에서 asset의 OAuth 로그인을 시작하세요. 조직 계정으로 로그인하고, 요청한 클라이언트·응답 주소·계정·읽기 권한을 확인한 뒤 직접 연결을 허용하세요. 로그인만으로 연결이 승인되지는 않습니다.

제공 권한은 조직 에셋 검색(읽기) 하나이며 도구는 org_asset_search입니다. 연결 확인은 실제 읽기 도구 응답으로 진행합니다. 에이전트 연결 안내: https://asset.madang.ai/agent-connections

연결 해제는 본인의 조직 사이트 ‘보안·내 계정 → 내 OAuth 연결’에서 합니다. 다른 조직의 연결은 해당 조직 주소에서 해제합니다. 공개 마켓 게시·실제 설치·원격 OAuth 수용은 별도 단계입니다.
